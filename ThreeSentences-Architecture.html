🎯 Key Architectural Patterns & Features

📱 Cross-Platform Architecture

Single codebase powers iOS, Android, and Web using React Native and Expo. File-based routing with Expo Router provides native navigation patterns.

🔐 Privacy-First Design

Client-side encryption for all journal entries before cloud sync. Data encrypted at rest using expo-crypto. Users have full control over their data.

⚡ Real-time Collaboration

WebSocket-based realtime messaging for direct and group chats. Supabase Realtime ensures instant message delivery and presence updates.

🧠 AI-Powered Insights

Reflection service analyzes journal entries using observational language. Built-in crisis detection triggers safety resources instead of automated analysis.

🎨 Immutable Journaling Philosophy

Entries become immutable after 24 hours, aligning with the "365 philosophy". One entry per day maximum, encouraging mindful reflection.

🔄 State Management Strategy

Domain-separated stores (auth, entries, chat, friends, profile) with AsyncStorage caching. Supabase handles persistence and cross-device sync.

🛡️ Row Level Security

Database-level access control ensures users only see their own data. JWT-based authentication with automatic policy enforcement.

🎬 Marketing Automation

Remotion-powered programmatic video generation for brand assets. Next.js landing page with waitlist integration for growth.

🔄 Critical Data Flows

1. Journal Entry Creation

User writes → Client-side encryption → Supabase entry table → Background sync → Cross-device availability

2. AI Reflection Generation

User requests → Fetch encrypted entries → Decrypt client-side → AI analysis → Crisis check → Display results or resources

3. Real-time Messaging

User sends message → Supabase insert → Realtime broadcast → Recipient receives → Read receipt update

4. Authentication Flow

Login attempt → Clerk auth → JWT issued → Token cached (SecureStore) → Supabase RLS validation → App access granted

5. Friend Request

Send request → Supabase friends table → Realtime notification → Accept/decline → Relationship established → Chat enabled

6. Profile Setup

Complete onboarding → Create profile → Set interests → Upload image → Profile completion flag → Enter main app
